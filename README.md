### 소개
안녕하세요, 백엔드 개발자 전혜진입니다.

병원에서 7년간 일하며 반복되는 업무를 보다가 개발에 관심이 생겼고, 더 성장하고 싶어 개발자가 됐습니다. 일하면서 컴퓨터공학과도 졸업했습니다.

지금은 매거진 정기구독 서비스에서 구독, 정산, 외부 CRM 연동을 맡고 있습니다.

### 일하는 방식
- 정산이나 배송 데이터가 어긋나면 원인을 끝까지 추적하고, 고치기 전에 그 보정이 다른 문제를 만들지 먼저 봅니다.
- 반복되는 수기 업무가 보이면 먼저 과제로 만들고, 출시 후 운영까지 맡습니다.
- 매일 업무일지를 쓰고, 반복되는 이슈와 처리 방법은 위키에 남겨둡니다.
